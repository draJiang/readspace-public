# Quipu — 07-C

沿用已选定的 07-C 三片展开图形，名称更新为 Quipu。

- 主色：#262626，RGB 38 / 38 / 38，实色炭黑。
- 主背景：#FFFFFF，RGB 255 / 255 / 255。
- 所有 white-bg 文件以及应用图标、favicon 都内置白底。
- transparent 文件为补充透明底资产，图形仍使用 #262626。
- 提供横向组合、上下组合、独立图形、字标和预览的 SVG / PNG。
- 字标沿用 DejaVu Sans Bold，已转为路径，无需安装字体。
- 保持宽高比例，图形周围预留至少其宽度 15% 的空间。

这份文件包是原 07-C 方案的名称和底色更新，与新一轮 Quipu 方向探索分开。
